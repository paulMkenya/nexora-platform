Setup Instructions — {{ brand.name }}

Brand {{ brand.name }} created successfully.

Complete the steps below before the brand is live.

{# Step 1: DNS #}

1 Point DNS to this server

Create the following DNS records at your domain registrar. Both domains must resolve to 162.220.165.68.

TypeNameValue
A {{ brand.primary_domain }} 162.220.165.68
A {{ brand.tracking_domain }} 162.220.165.68

Or use CNAME records pointing to cpa.cloudtrade.pro if your registrar supports CNAME flattening.

{# Step 2: NPM #}

2 Add proxy hosts in Nginx Proxy Manager

Open NPM Admin (127.0.0.1:81) and add two new proxy hosts — one per domain. Use the same settings for both:

Domain Names {{ brand.primary_domain }}
Forward Hostname nexora-web
Forward Port 8000
SSL Certificate Request a new Let's Encrypt certificate
Force SSL ✓ Enabled
HTTP/2 Support ✓ Enabled

Repeat for the tracking domain: {{ brand.tracking_domain }}

Note: Let's Encrypt requires the DNS A/CNAME records to be live and propagated before SSL issuance will succeed. Allow up to 10 minutes for DNS propagation.
{# Step 3: Verify #}

3 Verify

Once DNS and NPM are configured, verify with:

curl -I https://{{ brand.primary_domain }}/healthz
curl -I https://{{ brand.tracking_domain }}/healthz

Both should return HTTP/2 200.
