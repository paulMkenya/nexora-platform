Testing → Live workflow

Every offer you send to starts in TESTING: Nexora operator sets your leads' statuses manually (walking a test lead through new → test → test_ftd) so you can confirm your own source receives and records them correctly. Once confirmed, Nexora flips that offer to LIVE — from then on, the buyer's own reported status flows to you verbatim as the canonical value, both by postback and via the pull API below.

Postbacks (push)

Register a postback URL (API & Docs page or ask your Nexora contact) with any of these macros — resolved fresh on every delivery:

{% for m in doc.postback_macros %}{{ '{' }}{{ m }}{{ '}' }}{% if not forloop.last %} {% endif %}{% endfor %}

Every delivery is signed: X-Nexora-Signature: sha256=<hmac>, computed over the raw JSON body with your postback secret. Verify it before trusting the payload. Each payload also carries a per-lead status_seq — ignore any delivery whose seq is lower than one you've already recorded for that lead_id, so a late out-of-order retry can never regress a status you already have.

Pull (polling, the safety net)

GET {{ doc.base_url }}/api/leads?updated_since=2026-01-01T00:00:00Z — poll for what changed since your last check. Use this if a postback delivery to you ever fails; it's the same canonical status either way.
